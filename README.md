# Sentinel

**Native Windows system monitoring and diagnostics built with C++20.**

Sentinel is an open-source desktop application designed to provide real-time insight into system performance, running processes, and resource utilization.

## Planned Features

- Real-time CPU and memory monitoring
- Process inspection and resource usage
- Performance history and graphs
- Configurable resource alerts
- Local storage for historical metrics

## Technology

- C++20
- Qt 6
- CMake
- Windows Performance Data Helper (PDH)
- SQLite

## Development Status

Early development. Features will be implemented and documented incrementally.

## Platform

Windows 10 and Windows 11.
